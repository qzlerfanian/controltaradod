# Rahband ANPR

نسخه بازطراحی‌شده سامانه راهبند با سرویس پایتون روی لینوکس و رابط وب React.

کد قدیمی بدون تغییر در `legacy_source/` نگهداری شده است و فقط برای تطبیق رفتار و مهاجرت استفاده می‌شود.

## اصول معماری

- دوربین‌ها از تنظیمات سایت خوانده می‌شوند و محدود به چهار دوربین نیستند.
- هر دوربین دارای جهت `entry` یا `exit` است.
- تشخیص تصویر، تصمیم دسترسی، ثبت رویداد و کنترل رله از یکدیگر مستقل‌اند.
- SQL Server و MQTT فعلی حفظ می‌شوند.
- در قطع موقت شبکه یا دیتابیس، رویدادها ابتدا در صف محلی پایدار ذخیره می‌شوند.
- رابط React فقط از API و WebSocket استفاده می‌کند و مستقیماً به MQTT یا SQL Server متصل نمی‌شود.
- هیچ رمز، IP یا RTSP URL داخل کد نگهداری نمی‌شود.

جزئیات در [معماری](docs/architecture-fa.md) ثبت شده است.
